# Data Source: GHS-POP R2023A (2025 epoch)

**Source:** Global Human Settlement Population (GHS-POP), Release 2023A,
2025 epoch, at 100 m and 1 km spatial resolution, Mollweide projection.
(GHS_POP_E2025_GLOBE_R2023A_54009)

**Used for:** Estimating population within GHS-UCDB 2019 city polygons. Pixel
values are summed per UCDB polygon to produce the `GHSPOP2023` column used in
coverage and omission statistics and city-size classification.

**Raw raster files not stored in GitHub.** Both the 100 m and 1 km tiles are
excluded via `.gitignore` due to file size.
