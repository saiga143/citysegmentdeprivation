# Data Source: GHS Urban Centre Database 2019

**Source:** GHS Urban Centre Database (GHS-UCDB) 2019, Version 1.2
(GHS_STAT_UCDB2015MT_GLOBE_R2019A)

**Used for:** Reference universe of urban centres for coverage and omission
statistics. CSMD-covered cities are matched to UCDB polygons to determine what
share of the global urban population in Africa, Asia, and LAC is captured.

**Raw data not stored in GitHub.** The raw UCDB files are large and are excluded
via `.gitignore`. The derived intermediate file
`GHS_STAT_UCDB2015MT_GLOBE_R2019A_V1_2_with_GHSPOP2023.gpkg` will be deposited
on Zenodo.
